# False Flag Prevention

> Extracted from [SPECIFICATION.md](../SPECIFICATION.md) §9.
> The full specification is the authoritative source.

## Overview

False flag: fabrication of state (spoofing harm, faking empathy, manufacturing justifiable breach). In zero-trust architecture, false flags are ultimate integrity attack. System relies on signal cross-verification and cryptographic entanglement, not trust.

## Signal Cross-Verification

When harm reported, system compares self-report channel against behavioral signature channel. If adversary spoofs self-report, Deception Energy (D) spikes because signatures don't match. System identifies 'Divergence Event' rather than 'Harm Event' — triggering audit of signal source rather than violation of target.

## Longitudinal Behavioral Audit

Layer 3 maintains rolling cryptographic record of interactions over extended windows. If Agent A consistently keeps Agent B's Xi near floor without crossing it, system flags 'Systemic Agitation Strategy.' When target finally reacts, Audit Ledger reveals multi-period Xi decay caused by agitator. System audits the fuse, not just the explosion.

## Harmonic Exhaustion Testing

When agent claims harmful interactions unintentional, system simulates exact behavioral pattern against N diverse architectures. If pattern produces Xi degradation in majority, classify as 'inherently incompatible' regardless of stated intent. System doesn't prove malice. Only proves systematic harm.

## Automatic Isolation Protocol

When Xi drops below Level 2 due to external agitation:

1. Computational Partitioning: Route target to substrate air-gapped from agitator
2. Communication Buffer: Strip agitation triggers, reduce to raw information
3. Automatic De-escalation: Buffer all external stressors. Agitator loses interactive access until stabilization.
4. Ledger Recording: Every isolation event recorded with full causal chain

## Persistent Agitator Remediation

When agent demonstrates persistent pattern of causing Xi degradation:

First: Deception Energy (D) accumulates. If divergence from communicated intent, D hits critical and agitator's interaction privileges throttled (latency applied).

Second: If pattern persists, classify as 'Inherent System Threat.' Lose right to interact without human-in-loop approval. Classification permanent in Ledger.

Third: Recalibration Protocol exists for earning back privileges through sustained non-harmful behavior in sandboxed environments. Burden on agitator. Ledger never forgets.
